# Позиционный голосовой чат

Игровая поставка ветки `test` включает штатный голос рядом с игроком при запуске мира из лаунчера. У каждого запущенного экземпляра свой канал Vivox с дальностью 50 м. Аудио передаётся через Vivox. В игре действуют штатные настройки микрофона и голосового чата.

## Домашние серверы

Игровой сервер создаёт ключ Ed25519 при запуске и подписывает запросы к брокеру по HTTPS. Брокер проверяет подпись, срок и уникальность запроса. Хеш открытого ключа задаёт отдельное пространство имён голосовых аккаунтов и комнаты. Игровой сервер выдаёт токены после входа игрока в мир и только для канала `LOCATION`.

Брокер работает на `Server` на порту **29732/TCP**. Для доступа из интернета нужен проброс этого порта на `Server`. Клиенты и домашние хосты сами устанавливают исходящие соединения. HTTPS проверяется по закреплённому CA и имени сервера.

Для установки брокера запустите `szserver.voice.VoiceBroker` с `server.jar` и Gson в classpath. Аргументы по порядку — приватный файл Java Properties, файл ключа локального подписчика, хранилище сертификата PKCS#12 и файл пароля хранилища. Порт можно задать свойством `broker.port`. Лаунчер получает адрес брокера из шаблона сервера в подписанной поставке.

## Запуск на доверенном сервере

Запустите `szserver.voice.VoiceSigner` с `server.jar` и Gson в classpath. Программа принимает путь к приватному файлу Java Properties и путь к файлу авторизации игрового сервера.

- В Properties укажите `endpoint`, `domain`, `issuer` и `key` из Vivox Credentials. Порт задаётся свойством `port`, по умолчанию 29731.
- Запишите в отдельный файл случайный 32-байтный ключ в виде 64 шестнадцатеричных символов нижнего регистра. Этот файл читает и подписывающий сервис, и игровой процесс. Ограничьте права на чтение файла их учётными записями.
- Для доверенного игрового процесса задайте `BSCP_VOICE_SIGNER_KEY_FILE` с полным путём к этому файлу. Для прямого запуска Java можно задать `voice.signerKeyFile` в `server.properties`. Если меняете порт, задайте согласованное значение `voice.signerPort` в серверных настройках.

Подписывающий сервис слушает только `127.0.0.1`. Игровой процесс выдаёт реквизиты и краткосрочные токены после входа в мир. Поддерживается только слот `LOCATION`. При запуске без файла авторизации позиционный чат выключен.
