# Разбор issue #23 — 23.11.2026

Это список отдельных жалоб, а не один исправленный дефект. Проверялся актуальный сервер после выпуска native-item-editor-2026.11.23. Старые пользовательские сборки и точные сочетания всех обликов не были предоставлены.

| Пункт | Результат |
|---|---|
| Меню удержания C | Исправлено этим обновлением: штатное назначение, синхронизация, выбор и сохранение. Реальный клиент расходует одну выбранную единицу; четыре привязки пережили холодный запуск. |
| Заточка А-545, FAMAS, РПД | Основной отказ сохранения вложений уже исправлен предыдущим выпуском. Здесь повторно проверены +15 и нативный roundtrip восьми вариантов. Семь пушек, включая SIG, выданы с +15 и перемещены в слот рук реального клиента без вылета. Это не проверка всех анимаций и всех обвесов. |
| Вылет SIG / «карбач» | Для проверенного SIG вылет не повторился при выдаче и перемещении. Точное второе оружие, исходное NBT и обстоятельства неизвестны; весь пункт не закрыт. |
| Косметика ножей, ЗИВКАС, контейнеров | Уже использует исходные фабрики. Для выбранных ножей, контейнеров и моделей ЗИВКАС совпали ответы клиента и сервера; совместимая краска ставится/снимается. Модель 25495 не принимает обычную краску и в самом клиенте, но принимает совместимый специальный мотив. Правило не обойдено исключением. Все конкретные сочетания из жалобы не установлены. |
| Планка перед оптикой | СР-3М: 22923, Scorpion: 22919; затем 22206 в SIGHT_ON_MOUNT. В реальной сетевой сессии планки и оптика установились, исходные предметы списаны один раз. |
| Супы, холодец, завтрак | Все пять супов и холодец выдались. 70 завтраков образовали 64+6. Суп применён оригинальным запросом клиента, списалась одна единица и пришёл эффект. Полная физиология не объявляется идентичной оригинальному серверу. |
| Эльбрус | Предмет взят в руки и отрисован первым лицом. Поиск артефактов и сигналы этим тестом не проверены. |
| Перегрев и кровотечение | Есть частичная система состояний, но полная генерация и формулы по всем источникам не подтверждены. Требуется отдельная работа. |
| Хитбоксы ближнего боя | Есть серверные проверки дальности, направления и видимости. Полное совпадение с исходной игрой не подтверждено; этот пункт остаётся открытым. |

Новые изменения в этом выпуске относятся к C и его сохранению. Перечисленные рабочие механики заново не заменялись. Проверки косметики, весь серверный набор, установщик и две раскладки обновления прошли. На Linux игровой прогон не выполнялся. Клиентский HUD и физика оружия не изменены.
