# Открытые серверы BSCPCRAFT

В настройках сервера включите ретранслятор и «Отображать в списке открытых серверов», затем сохраните настройки. Лаунчер публикует запущенный мир, когда игровой сервер готов принимать подключения. Иконка задаётся там же. PNG, JPEG и WebP обрезаются по центру до 64×64. Прозрачность сохраняется.

На главной откройте «Серверы → Открытые», выберите мир и нажмите «Подключиться». Название берётся из метаданных запущенного мира, численность — из состояния игрового сервера. Лаунчер измеряет задержку запросом к Iroh-хосту по тому же приглашению. Значение может меняться, если игровое соединение позже перейдёт на другой маршрут.

Каталог работает отдельным процессом на Server. Игровой трафик проходит по штатным Iroh-туннелям. Публикация доступна через публичные ретрансляторы из `launcher/relays.json`. Каталог получает имя мира, число игроков, иконку и приглашение без прямых IP-адресов. Iroh подтверждает, что запись обновляет владелец соответствующего игрового узла. Записи живут 70 секунд и обновляются раз в 20 секунд. При завершении процесса каталога они заново появятся по мере обновления.

## Запуск сервиса

```powershell
.\BSCPCRAFT.exe --server-directory https://euc1-1.relay.n0.iroh.link./ --root .\directory-data
```

Для постоянной работы настройте автозапуск с перезапуском при сбое. Первый успешный запуск сохранит публичный адрес в `directory-data/config/server-directory.json`. Скопируйте его в `launcher/server-directory.json` для сборки лаунчера. Для тестового профиля можно использовать `config/server-directory.json` рядом с его настройками. Сохраните `config/public-directory-private.json` только на сервере. Этот ключ сохраняет идентичность каталога между перезапусками.
