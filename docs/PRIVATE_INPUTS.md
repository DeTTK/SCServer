# Частные входные данные

| Вход | Для чего нужен | В Git |
|---|---|---|
| закреплённый runtime/classes, bootstrap, libs, dependencies | native ABI и запуск клиента/адаптеров | нет |
| установленная игра assets/modassets | модели, текстуры, звук, конфиги | нет |
| серверные fixtures и registry | игровые определения и сериализованные примеры | нет |
| lootbox-tables.json.gz | таблицы добычи и наборы для кейсов; закреплённый ресурс серверного JAR | нет |
| native-item-metadata.json.gz | снимок размеров и лимитов настоящих фабрик, закреплённый ресурс серверного JAR | нет |
| исходная карта Map | регионы и реестр объектов | нет |
| Server/data | персонажи, журналы, checkpoint, admin token | нет |
| ключ подписи и TLS private key | собственный сервис доставки | нет |

`.local/paths.json` содержит только локальные пути, задаваемые `scripts/local.py configure`.
Не копируйте туда токены. В issue прикладывайте версии/хеши и очищенный stack trace.

Не подставляйте свежий официальный `classes.jar` вместо сохранённой базы автоматически:
смена обфускации и packet IDs требует проверки adapters, сериализаторов и hooks.
Сохраняйте один проверенный runtime и один откат вне публичного checkout.

Автоматического получения игровых файлов в публичном CI нет.
Отсутствие private inputs должно завершаться понятной диагностикой, а не попыткой скачать чужие данные.
