# Бонусы и стоимость перехода фракций

Экран «Выберите фракцию» получает состояние от сервера отдельным пакетом (id 1667). Без него
клиент остаётся на значениях по умолчанию и показывает «Вербовка временно приостановлена».
Сервер отправляет пакет при входе в мир и после каждого изменения настроек, поэтому клиент получает параметры без перезахода. Список строк бонусов в текущем
клиенте кешируется при открытии: после изменения процентов закройте и снова откройте меню.

## Настройки

Файл создаётся при первом запуске:

```
<каталог данных сервера>/alliance-settings.json
```

Для установки из исходников это `.local/server-state/data/alliance-settings.json`.

```json
{
  "duty": {
    "fee": 100000,
    "farm": 10.0,
    "delivery": 10.0,
    "quest": 10.0,
    "discount": 10.0,
    "buyer": 10.0,
    "ffa": 5.0
  }
}
```

| Ключ | Что показывает меню |
| --- | --- |
| `fee` | «Стоимость перехода», рубли (0…100000000) |
| `farm` | «+N% к добыче ресурсов» |
| `delivery` | «+N% к ресурсам за доставку» |
| `quest` | «N% к ресурсам за еж. задания» |
| `discount` | «-N% на расходники» |
| `buyer` | «+N% к ценам скупщика» |
| `ffa` | «+N% кэшбэка FFA» |

Значения бонусов — проценты, допустимы от -1000 до 1000. Фракции: `stalkers` (также `stalker`), `bandits` (также `bandit`),
`duty`, `freedom`, `merc`, `covenant`.

## Команды

Требуется администратор (`game.playerPermission=admin`).

```
/alliance                                  показать все значения и путь к файлу
/alliance help                             подсказка по синтаксису
/alliance reload                           перечитать файл и обновить меню у всех
/alliance duty fee 250000                  стоимость перехода «Рубежа»
/alliance duty farm 15                     задать бонус к добыче ресурсов
/alliance duty add delivery                добавить бонус (значение по умолчанию 5%)
/alliance duty add quest 25                добавить бонус со значением 25%
/alliance duty remove buyer                убрать бонус из меню
/alliance duty list                        какие бонусы сейчас показаны
```

Добавление и удаление работают через процент: клиент не рисует строку бонуса, если значение
равно нулю. Поэтому `remove` записывает `0` (строка исчезает из меню), а `add` возвращает
ненулевое значение — прежнее, если оно было, иначе 5%.

Ключи можно писать по-русски: `стоимость`, `добыча`, `доставка`, `задания`, `расходники`,
`скупщик`, `ффа`; вместо `add`/`remove` — `добавить`/`убрать`. Вместо `/alliance` работает
`/фракции`.

Набор бонусов фиксирован клиентом: добыча, доставка, задания, расходники, скупщик, FFA-кэшбэк.
Добавить бонус другого типа нельзя без правки клиента, но любую из шести строк можно скрыть
и вернуть.

Команда сразу сохраняет файл, поэтому изменения переживают перезапуск и не требуют правки
JSON вручную. Ручная правка файла применяется командой `/alliance reload`.

## Автодополнение

Мод `command-completion` подсказывает команды, фракции, `add`/`remove`, ключи бонусов и
типовые проценты. Каталог команд приходит с сервера, поэтому после обновления сервера
подсказка `/alliance` появляется автоматически; сам мод ставится в
`<клиент>/mods/command-completion.jar`.
## Сохранение и ошибки

Запись выполняется отдельным worker, очередь ограничена 32 ожидающими командами. Один игрок отправляет следующую команду после ответа на предыдущую. Новое состояние становится доступно меню после успешной записи временного файла и атомарной замены настроек. При ошибке сохранения или `/alliance reload` прежнее состояние остаётся активным; файл с ошибкой не перезаписывается. Настройки ограничены 64 КиБ, стоимость — целое число 0…100000000, бонусы — конечные числа -1000…1000.

## Что меняют эти настройки

Это конфигурация штатного меню выбора фракции: строки бонусов, отображаемая стоимость перехода и обновление открытого окна. Начисление бонусных ресурсов, скидки торговцев и списание денег за переход этим изменением не добавлены. Существующая команда `/fraction stalker|bandit|merc|freedom|duty|covenant` продолжает менять фракцию персонажа по прежней логике.

## Переход персонажа

Штатная кнопка выбора отправляет запрос 1232 (`1663926674`) с именем выбранной стороны или фракции. Сервер сохраняет выбор через ту же операцию, что `/fraction`, и отправляет обновлённые атрибуты персонажу и остальным подключённым игрокам. Выбор переживает перезаход и перезапуск. Повторный запрос во время сохранения не запускает вторую операцию. Переходы локалки используют прежнюю логику `/fraction`: отображаемая стоимость пока не списывается. Кнопка «Показать базу» отправляет другой запрос и к изменению фракции не относится.

Проверено в настоящем графическом клиенте: stalkers, bandits, duty, freedom, merc и covenant, переключение через штатное действие выбора, экран с процентными бонусами и без них, отметка «Вы член этой фракции», сохранение после перезапуска и повторного входа. Удаление процентных бонусов сохраняет две встроенные особенности «Рубежа» из ресурсов игры.
