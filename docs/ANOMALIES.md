# Аномалии

В дев-режиме наведи прицел на нужную аномалию и нажми **F** (штатная клавиша взаимодействия). Откроется родное окно «Настройки аномалии».

Общие поля штатного окна:

- название модели — справочная строка;
- шанс срабатывания;
- разрешение выпадения артефактов;
- переопределение пресета.

У батута (`tramp`) дополнительно доступны:

- перезарядка в тиках;
- сила;
- установка скорости вместо добавления импульса;
- отдельная перезарядка для каждого игрока.

Изменения отправляются штатным клиентом при закрытии окна. Сервер записывает их в свойства **выбранного объекта карты**, используя оригинальные имена полей: `ChanceOfWork`, `isArtefactDropDisabled`, `overriddenPresetId`, `cooldown_tick`, `trampoline_strength`, `trampoline_set_velocity`, `use_individual_cooldown_for_players`. Настройка одного батута не меняет остальные. Родной инструмент изменения силы также меняет тот же объект.

Отдельного серверного файла настроек аномалий нет. Базовые урон, радиусы и прочие параметры берутся из оригинальных игровых ресурсов, а доступные в штатном окне настройки — из свойств конкретного объекта.

Поддерживаются поведения `electra`, `tramp`, `funnel`, `carousel`, `lighter`, `steam`, `simple_anomaly` (кисель), `puh`, `stasis`, `mirror`, `circus`, `tesla`. Для проверки урона выйди из административного режима: в нём персонаж защищён.

Генератор артефактов пока не реализован. Его штатные поля сохраняются, но не создают добычу.

## Проверки

`szserver.AnomalyTests` проверяет оригинальный DTO, сохранение свойств каждого экземпляра, отсутствие чужих полей у обычных аномалий, состояния, урон, сопротивления и перезарядку. `szserver.world.AnomalyIndexTests` проверяет применение изменений и удаление из индекса без включения системы ботов. `szserver.client.ActorAnomalyMotionTests` проверяет родную физику NPC с игровыми ресурсами.
