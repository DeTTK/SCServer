# Проверки

Для обычного прогона из корня проекта:

```sh
python -m unittest discover -s scripts/tests
python scripts/build.py test
```

Нужны Python и JDK 17. Игровые файлы для этого набора не требуются. Результат сохраняется в `build/verification.json`.

Проверка авторизации `AuthenticationStabilityTests` делает 72 полных цикла: выдача токена по HTTP, проверка на gateway и получение персонажа для входа в мир. Проверяет кириллицу и пробелы в логине, разные имена аккаунта и персонажа, неверную сессию перед правильным входом, повтор токена, параллельные протоколы и восстановление после перезапуска хранилища. Данные синтетические, чужие сохранения не используются.

Это серверная проверка протокола, она не запускает игровой клиент. Отдельно нужен игровой прогон: выбор нескольких персонажей, повторный вход, экипировка, потеря соединения, перезапуск сервера и восстановление после смерти. Успешный `build.py test` не означает, что проверены все окна и игровые действия.
