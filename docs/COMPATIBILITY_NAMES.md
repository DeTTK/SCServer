# Брендинг и совместимость

Публичное название проекта — **BSCPCRAFT / Бскпкрафт**, интеграция — **BSCP**.
Имя репозитория остаётся SCServer.

При изменении названия не переименовываются внешние Java-пакеты и native entry points,
DLL и JVM properties, имена manifest-файлов модов, сигнатуры форматов replay/registry,
диагностический идентификатор HTTP-службы и пространства имён идентификации аккаунтов.
Они являются контрактом с клиентом, установленными модами и уже сохранёнными данными.
Исторические имена в этих технических значениях сохранены намеренно.

Изменены заголовки окон, текст настроек, примеры путей, описание проекта и комментарии.
Проверка токенов исходников подтвердила: исполняемый код изменён только в трёх
презентационных строках; остальные изменения кода относятся к комментариям.
Сторонние лицензии и уведомления об авторстве зависимостей сохраняются.
