# Экспорт области SCServer в Axiom

Распакуйте **SCServer-AreaExport-Windows.zip** в папку локалки, в которой находится Client. В Client/mods появятся area-export.jar и папка area-export с программой конвертации. Перезапустите клиент. Python, pip и JDK игроку устанавливать не нужно.

Встаньте в первом углу и нажмите **F7**, затем во втором и нажмите **F8**. **F9** открывает меню. Можно сразу открыть F9 и вручную указать обе точки. Координаты включают граничные блоки. Меню также запускается двойным щелчком по **Client/mods/area-export/AreaExport.exe**.

Выберите сохранённую карту SCServer (папку с region и registry.json), проверьте координаты и укажите, куда записать .schematic. В Axiom загрузите этот файл как схему. Для общей карты игроку нужна локальная копия сохранённого экспорта карты с нужными правками: конвертер читает файлы карты на его компьютере. Одна папка базовой карты не включает изменения из серверного журнала.

Экспортируются блоки, поддерживаемые формы и покрытия, а также декор с центром внутри области. Неизвестные модели перечисляются в соседнем файле .report.txt. При наличии соответствия в каталоге сохраняется номер варианта материала. Процедурные провода и произвольная индивидуальная окраска пока не переносятся.

## Сборка для распространения

Windows x64, JDK 17+, Python 3.13. В отдельном виртуальном окружении выполните:

    python -m pip install -r mods/area-export/requirements.txt
    python mods/area-export/build.py

Готовый архив появится в build/SCServer-AreaExport-Windows.zip.
