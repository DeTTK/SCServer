# STALCRAFT VR

В лаунчере откройте «Моды», установите STALCRAFT VR и перезапустите клиент. Подключите шлем и контроллеры к OpenXR, войдите в мир и нажмите F12. Повторное нажатие завершает сеанс VR.

Для мода нужен Windows x64. Сборка лаунчера поставляет библиотеки OpenXR вместе с игровым комплектом. Мод воспроизводит звуки действий из ресурсов установленной игры.

Сборка игрового каталога генерирует адаптеры под поставляемые классы и проверяет управление, сетевой протокол перезарядки, профили оружия и оптику.

Высоту правых кобур, их боковое смещение, высоту левого подсумка и силу отдачи можно изменить во вкладке «Виртуальная реальность» в настройках игры. Основное оружие берётся правым хватом у плеча, вторичное — у пояса.
