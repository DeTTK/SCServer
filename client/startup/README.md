# Совместимость запуска клиента

`StartupTextureAgent.java` сохраняет штатный экран загрузки, добавляет известные игре имена типов ресурсов и причин GC. Во время загрузки отдельный daemon-поток заранее инициализирует таблицы CLDR. Поэтому первый tooltip с величинами не запускает этот расчёт в потоке отрисовки. Операции OpenGL в этот поток не переносятся.

Сборка требует JDK 17, Python 3 и [ASM 9.7.1](https://repo.maven.apache.org/maven2/org/ow2/asm/asm/9.7.1/asm-9.7.1.jar). Скрипт проверяет SHA-256 библиотеки, включает её лицензию и помещает ASM в собственный пакет, чтобы не подменить версию игры.

```sh
python client/startup/build.py --asm /path/to/asm-9.7.1.jar
```

Результат — `build/startup-guard.jar`. Установщик кладёт его в `Client/compat/startup-guard.jar`; для ручной замены сначала закрой клиент. Игровые классы и сохранения агент не переписывает. Сам по себе этот агент не доказывает исправление серверных фризов из #18: это отдельная подтверждённая клиентская пауза.
