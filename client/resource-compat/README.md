# Совместимость ресурсов и камеры

В этой папке исходники адаптера ресурсов и сетевых форматов. Для #28 добавлена `PerspectivePolicyTransformer`: она убирает только проверку режима разработчика в штатном контроллере камеры. F5 переключает первый вид, вид сзади и спереди в обычной игре. Клавиша берётся из штатных настроек; математике камеры, прицеливанию, коллизиям и отрисовке правка ничего не добавляет. Флаг разработчика `idev` (сетевой атрибут 217) не меняется.

Агент проверяет хеш игровой камеры и структуру нужного метода. Если версия другая, эта необязательная правка пропускается с записью в лог, остаётся штатное поведение. Файлы игровых классов на диске не переписываются.

## Сборка правки поверх предыдущего агента

Нужны JDK 17, Python 3, [предыдущий агент](https://github.com/DeTTK/SCServer/releases/download/world-items-2026.11.22/game-resource-compat-udp-20261122.jar), [ASM 9.7.1](https://repo.maven.apache.org/maven2/org/ow2/asm/asm/9.7.1/asm-9.7.1.jar) и [ASM Tree 9.7.1](https://repo.maven.apache.org/maven2/org/ow2/asm/asm-tree/9.7.1/asm-tree-9.7.1.jar). Их SHA-256 проверяет скрипт. Он пересобирает два изменённых семейства классов и сохраняет остальные записи JAR побайтово, включая прежние исправления ресурсов, UDP и интерфейса.

```sh
python client/resource-compat/build.py --base-agent game-resource-compat-udp-20261122.jar --asm asm-9.7.1.jar --asm-tree asm-tree-9.7.1.jar
```

Результат — `build/game-resource-compat-agent.jar`. Для дополнительных проверок можно передать `--native-camera /path/to/runtime/classes/1389510037.class`. Это вход только для чтения: тест проверит неизменность всех остальных методов камеры и безопасный отказ на незнакомой версии. Сам игровой класс в репозиторий не входит.

Обновление готовой локалки: закройте игру и сервер и запустите свежий `BSCPCRAFT-Setup.exe`. При ручной установке сохраните предыдущий `Client/compat/game-resource-compat.jar` и замените его новым агентом. Сервер, карту и персонажей это обновление не меняет.
