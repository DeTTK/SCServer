# Подсказки команд

В чате начните писать команду с `/`. **Tab** подставляет вариант, повторный Tab выбирает следующий. **Shift+Tab** идёт назад, **↑/↓** меняют выбранную подсказку. **Esc** скрывает список. **Enter** отправляет команду как обычно.

Список команд, игроков и клонов приходит от сервера. Названия анимаций берутся из клиента. Поиск работает и по части названия; имена с пробелами заключаются в кавычки автоматически.

Свежий установщик кладёт мод в `Client/mods/command-completion.jar`. Для ручной установки положите JAR туда же и перезапустите клиент. Нужны клиентские hooks из совместимого комплекта локалки; одного JAR в произвольном клиенте недостаточно.

Сборка из корня репозитория:

```sh
python scripts/build.py command-completion
```

Получится `build/command-completion.jar`. Проверки кавычек, Unicode, положения курсора и подбора аргументов запускаются при сборке.
