# Базовая карта

Первый launtest использует `Map` установленной проверенной основы. Манифест build-ветки явно сообщает об этом. Существующие миры сохраняют свою content-v2 базу; обновление сервера или клиента не заменяет карту мира.

В дальнейшем подготовленные файлы новой карты и их индекс будут публиковаться сюда сборщиком. Пользовательские миры, журнал, персонажи и резервные копии в репозиторий не попадают.
