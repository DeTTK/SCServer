# Основная карта

Карта `merged-netdecode-20261128-chunk-snapshots` собрана из записей netdecode. В ней 144 669 чанков, 249 регионов и 992 049 объектов.

Сборка выбирает самый свежий полный снимок каждого чанка. Рельеф и оба канала объектов берутся из этого снимка. Для 507 чанков доступны только записи объектов без исходного рельефа. В проверенной центральной зоне «Кузни-11» из 680 чанков убраны 8 712 объектов, отсутствующих в выбранных снимках.

В `default.json` закреплены идентификатор карты, результаты сверки и SHA-256. CI собирает файлы из Git-входов в `map/data` и публикует их в `build-main` в составе подписанной доставки. Размеры и SHA-256 каждого файла карты закреплены в `bootstrap/input-manifest.json`.

Новые миры используют эту основу после обновления игровых компонентов. Для существующих миров лаунчер открывает их собственную копию карты.
