# Основная карта

Основная карта `merged-netdecode-20261121-registry-r3` собрана из записей netdecode. В ней 144 669 чанков, 249 регионов и 1 075 086 объектов. В редакции `registry-r2` исправлены 4 613 ID типов объектов из ранних записей `KV` и `Test`. Версии исходных реестров сверены по времени пакетов и совпадающим UUID.

Редакция `registry-r3` исправляет 636 объектов Госпиталя и его окраин по записи от 3 июня и реестру `07.06`.

`default.json` фиксирует источник, статистику, результаты сверки и SHA-256 реестров. CI собирает файлы карты из Git-входов в `map/data` и публикует их в `build-main` в составе подписанной доставки.

Новые миры используют эту основу после обновления игровых компонентов. Существующие миры сохраняют свой content-v2 Map и настройки форматов объектов; автоматического переноса сохранений на новую карту нет. Сервер выбирает `object-codecs.json` рядом с картой, при его отсутствии использует прежнюю серверную копию.

В 507 чанках записаны объекты без исходного рельефа. 45 исторических объектов сохранены в карте, но отсутствуют в текущем каталоге ресурсов и не загружаются сервером. Полнота вне доступных записей не предполагается.

При замене регионов обновляются SHA-256 и размеры соответствующих входов в `bootstrap/input-manifest.json`. Полная сборка проверяет эти данные и переводит объекты из реестра карты в реестр клиента перед публикацией.
