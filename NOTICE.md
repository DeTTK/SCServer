# Лицензия и происхождение

Владелец проекта отложил выбор лицензии. Файл `LICENSE` намеренно не добавлен.
Нельзя представлять этот кандидат как уже лицензированный MIT/GPL-проект.
SCServer публикуется без выбранной лицензии по решению владельца. Публикация не предоставляет отдельную лицензию на использование кода; происхождение импортированных фрагментов ещё требует ручной проверки.

Копирование исходников в этот каталог и автоматический аудит не являются подтверждением прав на них.
Перечень файлов и локальных преобразований находится в `source-manifest.json`.
Сторонние заголовки и уведомления в исходниках должны сохраняться.

Классы оригинальной игры, защищённая JVM, распакованные дампы, игровые ресурсы,
карты, материалы из других игр и скачанные reference-репозитории в этот экспорт не включены.
Условия выбранной впоследствии лицензии собственного кода не должны автоматически распространяться на такие материалы.

GitHub отдельно объясняет последствия публикации без лицензии:
[Licensing a repository](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
