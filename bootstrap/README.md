# Основа игры

В `build-main` и `build-test` опубликована полная игровая основа: Java 17, клиентские и серверные runtime-файлы, нативные библиотеки, bridge и карта. `delivery/foundation.lock.json` закрепляет её корневой индекс. Лаунчер может установить игру в пустую папку без старого комплекта и без игровых архивов из Releases.

`base.lock.json` закрепляет проверенные входы сборки. Из серверного JAR импортируются только шесть ресурсов по отдельному lock-файлу. Входной клиентский агент сохраняет закрытые вспомогательные части; все опубликованные исходники gamecompat пересобираются поверх него. Основная карта остаётся отдельной неизменяемой базой миров.

Индекс содержит 387875 файл (около 2.02 GB после установки). Повторяющиеся данные хранятся один раз; блоки и сжатые индексы занимают около 935 MB. Каждый блок меньше лимита обычного Git-файла. `scripts/export_foundation.py` готовит новую основу; она получает новый идентификатор содержимого. CI при обычных правках сохраняет основу и публикует только новые собственные компоненты.

Оригинальные игровые ассеты выбираются из установленной игры при первом запуске; это отдельный путь, они не публикуются с дополнительным runtime локалки.

Основная карта — объединённая netdecode от 21.11.2026; сведения закреплены в `map/default.json`. При замене карты остальные runtime-объекты сохраняются.
