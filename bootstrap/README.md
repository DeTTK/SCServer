# Основа игры

В `build-launtest` опубликована полная игровая основа: Java 17, клиентские и серверные runtime-файлы, нативные библиотеки, bridge и карта. `delivery/foundation.lock.json` закрепляет её корневой индекс. Лаунчер может установить игру в пустую папку без старого комплекта и без игровых архивов из Releases.

`base.lock.json` закрепляет проверенные входы сборки. Из серверного JAR импортируются только шесть ресурсов по отдельному lock-файлу. Входной клиентский агент сохраняет закрытые вспомогательные части; все опубликованные исходники gamecompat пересобираются поверх него. Основная карта остаётся отдельной неизменяемой базой миров.

Индекс содержит 387861 файл (около 1.96 GB после установки). Повторяющиеся данные хранятся один раз; блоки и сжатые индексы занимают около 844 MB. Каждый блок меньше лимита обычного Git-файла. `scripts/export_foundation.py` готовит новую основу; она получает новый идентификатор содержимого. CI при обычных правках сохраняет основу и публикует только новые собственные компоненты.
