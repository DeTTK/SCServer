# Основа игры

В launtest CI собирает собственные изменяемые компоненты поверх проверенной основы `bootstrap-ad0119c8978df19a`. Java, оригинальные классы и нативные библиотеки не пересобираются после каждой правки. Игроку на первом этапе нужен установленный комплект Client / Server / Map, который уже умеет готовить лаунчер.

`base.lock.json` закрепляет проверенные входы сборки. Из серверного JAR импортируются только шесть ресурсов по отдельному lock-файлу. Входной клиентский агент сохраняет закрытые вспомогательные части; все опубликованные исходники gamecompat пересобираются поверх него. Основная карта остаётся отдельной неизменяемой базой миров.

Это переходная основа тестового канала. Полностью автономная первоначальная доставка Java/классов/карты из build-ветки здесь ещё не заявлена.
