# Обзор SDK

SDK позволяет расширить совместимый клиент BSCPCRAFT обычным Java-модом: добавить
HUD, настройки, клавиши, обработку ввода и вмешаться в отдельные игровые пути через
хуки.

<Callout title="Только клиент">
  Публичный API работает на клиенте. Серверного API модов нет. Мод загружается
  только в совместимый клиент и не превращает произвольную сборку игры в BSCPCRAFT.
</Callout>

## Требования

- JDK 17.
- Мод — JAR с классом, реализующим `szmods.api.ClientMod`.
- В корне JAR лежит `stalcraft-mod.properties`.
- JAR компилируется против `build/mod-api.jar` и не тащит свои копии API.
- Внутренние классы игры не входят в контракт: их ABI меняется между версиями клиента.

## Где что лежит

| Путь | Назначение |
| --- | --- |
| `sdk/api/szmods/api/` | публичный API версии `1` |
| `sdk/example/` | пример `HelloMod` и манифеста |
| `client/mod-runtime/src/szmods/runtime/` | загрузчик, регистры и call sites хуков |
| `client/command-completion/` | рабочий мод подсказок команд |
| `mods/<name>/` | исходники десяти модов, без рецептов сборки |
| `docs/SDK.md` | исходный справочник в репозитории |

Копия API в `client/mod-runtime/src/szmods/api/` должна совпадать с `sdk/api/`.

## Первый мод

<Steps>
<Step>
  Изучите `sdk/example/src/example/HelloMod.java` и
  `sdk/example/stalcraft-mod.properties`.
</Step>
<Step>
  Скопируйте пример в свой пакет и измените `id`, `main`, название и сообщения.
</Step>
<Step>
  Соберите API и пример:

  ```sh
  python scripts/build.py sdk
  ```
</Step>
<Step>
  Положите `build/hello-mod.jar` в папку `mods` совместимого клиента.
</Step>
<Step>
  Перезапустите клиент и проверьте `mods/loader-<pid>.log`.
</Step>
</Steps>

## Что умеет API

- **Настройки** — вкладка в штатном меню ESC, сохранение значений в
  `mods/config/<id>/settings.properties`.
- **Клавиши** — объявление привязок и чтение ограниченного набора клавиш из
  `InputSnapshot`.
- **HUD** — собственные оверлеи и декларативные элементы раскладки.
- **Тики и кадры** — детерминированные `onTick` с шагом 1/240 с и `onFrame`.
- **Хуки** — точечное вмешательство в ввод, камеру, оружие, HUD, сеть, VR и видео.

## Ограничения

<Callout title="Стабильность">
  API `1` не обещает совместимости с будущими версиями. При `api=1` мод
  загружается, при другом значении — пропускается. Внутренние классы игры и
  полу-публичный слой `szmods.runtime.*` могут меняться без смены версии API.
</Callout>

- Один JAR не даёт гарантий между разными версиями клиента.
- Reflection по обфусцированным именам пишите защитно: проверяйте наличие класса,
  аргументы, возвращаемый тип и `static`/`instance`.
- Мод видит классы игры и других модов. Ставьте только доверенные JAR.
