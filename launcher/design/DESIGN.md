# BSCPCRAFT · нативный интерфейс

## Основа

Лаунчер начинает игровую сессию с выбора мира или адреса. Архитектура аванпоста и тёплый свет над лесом задают палитру. Крупное изображение закрепляет игровой контекст на главной и при первом запуске. На рабочих экранах место занимают данные сохранений, хоста и установленных файлов.

| Цвет | Назначение |
| --- | --- |
| #181A1C | Фон рабочей области |
| #202224 | Боковая навигация, поверхность панели |
| #2B2D30 | Вторичная кнопка или поднятый элемент |
| #F3AC4B | Главная команда и индикатор выбора |
| #F1F0EA | Основной текст |
| #AFAFA9 | Подписи и справка |

Russo One используется для марки BSCPCRAFT. Segoe UI отвечает за русские заголовки, действия, значения и пояснения. Шкала 13, 14, 16, 21, 24 и 32 логических пикселя. Основные интервалы 4, 8, 12, 16, 24 и 32. Поле ввода высотой 38 пикселей. Системная рамка Windows сохраняет привязку, изменение размера и оконные сочетания клавиш.

## Компоновка

    Марка  | Заголовок раздела                         Ник
    Раздел | Панорама и выбор мира     | Серверы
           | Журнал изменений          | Список и адрес
    Версия | Синглплеер      Подключиться      Создать сервер

Главная объединяет выбор мира с панорамой. Панель серверов остаётся рядом со свободным полем адреса. Журнал получает собственную область прокрутки при длинном содержимом. Остальные разделы наследуют ту же сетку, шрифты, поля и кнопки. Диалоги используют те же компоненты. Мастер заменяет рабочий экран целиком на период настройки. На экране нет повторной подписи мира над действиями и подзаголовков запуска.

Из чернового направления исключены надпись поверх неба, ряд однотипных карточек и декоративные показатели готовности. Изображение остаётся главным акцентом, а янтарная заливка обозначает доступное основное действие.

## Экраны и состояния

| Раздел | Действия и состояние |
| --- | --- |
| Главная | Название выбранного мира располагается на затемнённом нижнем крае панорамы. «Сменить» открывает список миров. Строка сервера переносит адрес в поле подключения. Empty state предлагает добавить избранный сервер. Журнал изменений всегда имеет своё место. |
| Мои миры | Одна колонка для сохранений, другая для команд выбранного мира. Удаление раскрывается через «Другие действия». Подтверждение требует ввести полное название мира. Восстановление указывает мир и заменяющую его копию. |
| Мой сервер | Слева статус, адреса, время работы, память и управление. Справа живой состав игроков. Для остановленного сервера, пустого состава и отсутствия ответа предусмотрены разные сообщения. |
| Первый запуск | Три последовательных шага с индикатором на иллюстрированной панели. Пути и ник, проверенный комплект, подготовка мира. Возврат сохраняет ввод. На работающей операции доступна отмена, показан переданный этап или процент. |
| Настройки | Основное, клиент, сервер и обновления открываются в одном представлении. Общие поля первого запуска и основных настроек используют один шаблон. Сохранение вынесено под область прокрутки. |
| Диагностика | Описание сбоя и отдельный выключенный по умолчанию флажок JFR. Кнопка явно создаёт локальный архив. |
| Диалоги | Фокус остаётся в активном представлении. Escape закрывает диалог или возвращает из подтверждения восстановления к резервным копиям. Активная операция завершается через обработчик. В справке о лаунчере встроен стандартный AboutSlint. |

Контракт моделей находится в `ui_contract.md`. Массивы записей, серверов, игроков и миров по умолчанию пусты. Для неизвестных метрик предусмотрено «Нет данных». Статусы установки, доступности узла и создания отчёта поступают из Rust.

## Общие элементы

- **Action** объединяет основной янтарный, обычный, текстовый и предупреждающий варианты. Наведение и нажатие меняют заливку. Фокус выделяется рамкой 2 px. Отступы и геометрия остаются постоянными.
- **Entry и Field** объединяют видимую подпись, рамку ввода, выбор папки и исправление ошибки. Путь может выходить за ширину поля, курсор прокручивает содержимое. Многострочный ввод используется для описания сбоя.
- **RowButton** обозначает выбор цветом подложки и янтарной вертикальной полосой. Основной текст имеет приоритет перед вторичными сведениями. Панорамное изображение, шрифт Russo One и системные знаки Segoe MDL2 Assets сохраняют исходные пропорции.
- **Notice** выводит текст ошибки или ход операции. При известной доле загрузки отображается полоса прогресса. Неизвестная длительность показывается текстом этапа.
- **Scroller** ограничивает прокрутку длинных списков и форм их областью. Основные действия находятся за пределами прокручиваемой области.

Цвета текста и фона дают контраст 15,28:1 для основного текста на рабочем фоне, 7,24:1 для подсказок на панели и 8,61:1 для текста основной кнопки. Цвет предупреждения на своей подложке даёт 7,59:1. Декоративная анимация отсутствует.

## Применённые рекомендации и проверка

Локальный frontend-design использован для выбора единственного визуального акцента, сокращения вспомогательного текста, композиции на реальных сценариях и ревизии по снимкам. В локальной базе ui-ux-pro-max запросы «desktop game launcher» и «gaming platform» использованы для проверки направления, а «keyboard focus visibility» и «error clarity validation» для навигации и обратной связи. Реализация использует общую палитру, фокусируемые кнопки, доступные подписи, ошибки у полей и фиксированные размеры контролов. За типографику и палитру отвечает утверждённое направление проекта.

Снимки сняты через Slint 1.19.0 с Windows-бэкендом winit и программным рендерером. Изолированный проверочный процесс подставлял только данные в памяти. Главная проверялась при 1120 × 760 и 1440 × 960, остальные страницы и диалоги при 1120 × 760. По снимкам исправлены кадрирование аванпоста, положение маркера выбора, вертикальное выравнивание марки и размер блока AboutSlint. Отправка событий Slint проверила выбор второго мира в раскрытом списке, переход в настройки, переключение вкладки через Tab и Enter, ввод кириллицы и закрытие диалога через Escape. Сводка экранов сохранена в `qa/native-screens.webp`. Полноразмерный снимок главной с пустыми списками находится в `qa/native-home.webp`.
