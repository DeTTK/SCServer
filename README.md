# SCServer

Неофициальные серверные сервисы, средства совместимости клиента, SDK модов и Windows-лаунчеры.
Это **кандидат исходников для первой публикации**, подготовленный 18.11.2026.
Лицензия собственного кода пока не выбрана; проект пока не обозначается как open source.

## С чего начать

**Разработчику:** установите JDK 17 и Python 3.10+, затем из корня проекта выполните:

```sh
python scripts/audit_public.py
python scripts/build.py test
```

Скрипт проверит SHA-256 двух зависимостей, соберёт Java-сервер, SDK и пример мода,
выполнит тесты чтения регионов и восстановления журнала. Игровые файлы для этих проверок не нужны.
Результат: `build/server.jar`, `build/mod-api.jar`, `build/hello-mod.jar`, `build/verification.json`.
Первый запуск скачивает закреплённые зависимости с Maven Central.

**Для игры:** нужен отдельный совместимый комплект клиента, сервера и карты,
а клиенту также нужна установленная игра. Настройка описана в [быстром старте](docs/QUICKSTART.md).
Игровые классы, ресурсы, DLL и карта в Git не входят. Их публичное распространение требует отдельного решения о правах.

## Что здесь работает

| Компонент | Статус этого каталога |
|---|---|
| Java-сервер | исходники собираются на JDK 17; независимые тесты запускаются |
| SDK и HelloMod | собираются без игры; пример готов для проверки в совместимом клиенте |
| GUI клиента и монитора сервера | собственный C#-код, сборка на Windows |
| Клиентский bridge и resource compatibility | исходники; интеграция требует закреплённой частной игровой базы |
| Полные моды | исходники в `mods/`; их сборка и игровой smoke-test пока вне публичного CI |
| Полная игровая поставка из одного checkout | ещё не воспроизведена; см. [ограничения](docs/STATUS.md) |

Сервер из этих исходников проверен с совместимыми приватными ресурсами: обычная карта,
готовность/здоровье, выдача игровой сессии и штатное сохранение при остановке.
Полная сессия с графическим клиентом и сборка всех модов пока не проверены.
Порядок запуска своего JAR описан в [быстром старте](docs/QUICKSTART.md).

## Структура

```text
server/          Java-сервисы и независимые тесты
sdk/             API v1 и минимальный пример мода
client/          собственный bootstrap, hooks и resource compatibility
desktop/         Windows GUI: локальный клиент, монитор и legacy-лаунчер
mods/            исходники модов, без моделей, звуков и игровых данных
scripts/         сборка, аудит и подключение локальных комплектов
config/          примеры конфигурации
docs/            запуск, архитектура, вклад и план публикации
.local/          частные входные данные и настройки; игнорируется Git
build/           результаты сборки; игнорируется Git
```
