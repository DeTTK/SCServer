## Дисклеймер

Проект выложен для изучения и своих экспериментов. Продавать его, сборки на его основе и доступ к ним не надо. Если решите на этом зарабатывать — с правообладателями будете разбираться сами. Это не разрешение торговать чужой игрой и её ресурсами.

Права на оригинальный клиент, ресурсы и сторонние библиотеки остаются у их правообладателей. Лицензию на свой код пока не выбирали.

## Что где лежит

- `server/` — код Java-сервера.
- `client/` — загрузчик модов и правки совместимости клиента.
- `desktop/` — исходники лаунчера и окна управления сервером.
- `sdk/` — API для модов и простой пример `HelloMod`.
- `scripts/` — скрипты сборки и запуска.
- `docs/` — подробные инструкции, если коротких ниже не хватило.
- `build/` — сюда попадает собранное. Папка появится после сборки.
- `.local/` — местные настройки, зависимости и данные тестового сервера. В Git не отправляются.

Для игры нужны совместимые папки `Client`, `Server`, `Map` и установленный клиент Бскпкрафта. [Исходная карта скачивается здесь](https://github.com/DeTTK/SCServer/releases/download/original-map-2026.11.20/Map-20261118.zip) — 254 МБ, без серверных построек. Распакуйте архив рядом с `Client` и `Server`: должны появиться `Map/region` и `Map/registry.json`. Сам `git clone` карту и готовые клиентские/серверные файлы не скачивает.

## Скачать и запустить

**[Скачать установщик BSCPCRAFT-Setup.exe](https://github.com/DeTTK/SCServer/releases/download/equipment-2026.11.22/BSCPCRAFT-Setup.exe)**

1. Откройте установщик.
2. Выберите, куда поставить локалку. Папку по умолчанию можно оставить.
3. Укажите уже установленную игру — папку с `classes.jar`, `assets` и `modassets`.
4. Введите ник и нажмите **«Скачать, установить и играть»**.
5. Дождитесь загрузки и распаковки. Потом сами запустятся сервер и клиент.

Установщик скачивает клиентскую часть локалки, сервер, исходную карту и Java. Скачается около **1,3 ГБ**, для установки нужно около **5 ГБ свободного места**. Саму установленную игру он не скачивает — её надо иметь отдельно. Python, JDK и настройка PATH для игры не нужны.

Если загрузка оборвалась, снова запустите установщик и выберите ту же папку: он продолжит скачивание. Архив проверяется по SHA-256. Папку с чужими файлами установщик не перезаписывает.

После установки запускайте **`Local/Играть.exe`** в выбранной папке. В первый раз установщик сам передаст ему ник и путь к игре. Оставьте это окно открытым, пока играете: в нём работает сервер. Когда закончите — **«Сохранить и остановить»**.

Сохранения лежат в **`Local/Server/data`**. Не удаляйте эту папку, если хотите сохранить персонажей и постройки.

Игра из Steam тоже подходит. Выбирайте корень с `assets`, `modassets` и `bin_ru`/`bin_global` — файлы переносить не надо. Для Linux через Wine есть [короткая инструкция](docs/QUICKSTART.md#linux-и-steam-через-wine).

### Обновить установленную локалку

Закройте игру и окно сервера. Откройте свежий установщик и выберите ту же папку. Он скачает только необходимые исправления (до 20 МБ), без повторной загрузки клиента и карты. Сохранения остаются на месте. Если распаковывали ZIP вручную, выберите папку с `Client`, `Server`, `Map` и `Играть.exe`.

Исправлены повторный вход с `gateway_token_mismatch`, вход с бронёй Дио/Джотаро и админской гаусс-пушкой, размеры предметов и слот ПНВ. Старые пересекающиеся предметы сервер разложит заново без удаления; если рюкзак заполнен, перенесёт их на личный склад. Обновление сервера входит в свежий установщик; прежний `server.jar` сохраняется в `.setup/previous-server.jar`.

Можно вручную: [маленький ZIP-патч](https://github.com/DeTTK/SCServer/releases/download/anomalies-2026.11.22/BSCPCRAFT-anomalies-20261122.zip). Распакуйте с заменой в папку с `Client`, `Server` и `Map`, предварительно закрыв игру и сервер.

### Если хочется распаковать вручную

[Полный архив локалки — 1,3 ГБ](https://github.com/DeTTK/SCServer/releases/download/local-ready-2026.11.20/BSCPCRAFT-local-20261119.zip). Распакуйте целиком в отдельную папку и откройте `Играть.exe`. Выберите установленную игру, введите ник и нажмите запуск.

Внутри уже есть `Client`, `Server`, `Map` и Java. `Client/Launcher.exe` и `Server/ServerManager.exe` оставлены для ручного запуска и подключения к другому компьютеру.

При вылете пришлите последний `client-*.log` из `Local/Client/logs`. При ручной распаковке — из `Client/logs`. Если в этой же папке есть `hs_err_pid*.log`, приложите его тоже. Код `-1` сам по себе причину не объясняет.

Кнопка Code → Download ZIP на GitHub скачивает **исходники**. Для игры используйте установщик или полный архив по ссылкам выше.

## Собрать сервер самому

Если непонятно, какую папку или версию игры выбирать, см. [раздел быстрого старта](docs/QUICKSTART.md#какую-версию-игры-выбирать).

Нужны **JDK 17** и **Python 3.10+**. `java` и `javac` должны быть в `PATH`, либо задайте `JAVA_HOME`. Команды ниже выполняются из папки репозитория.

Проверить, что всё собирается:

```sh
python scripts/build.py test
```

Для игрового запуска нужны ресурсы из совместимого готового сервера. Подставьте свои пути:

```sh
python scripts/import_private_resources.py --server-jar "C:/LocalGame/Server/server.jar"
python scripts/build.py server --private-resources
python scripts/run_server.py --bundle "C:/LocalGame/Server" --map "C:/LocalGame/Map"
```

Так запустится **ваш `build/server.jar`**. Его сохранения лежат отдельно: `.local/server-state/data`. Оригинальная карта остаётся на месте.

У этого способа адрес по умолчанию — **`127.0.0.1:29544`**. В лаунчере укажите именно его. Если хотите играть с другого компьютера, добавьте к последней команде `--host IP_КОМПЬЮТЕРА`. Остановка — Ctrl+C, потом дождитесь завершения Java.

После `build.py test` перед игрой снова выполните `build.py server --private-resources`: тестовая сборка не содержит игровых ресурсов.

Лаунчер и окно сервера собираются на Windows командой `python scripts/build.py desktop`. `BSCPCRAFT-Setup.exe`, `Играть.exe`, `Launcher.exe` и `ServerManager.exe` появятся в `build/desktop/`. Одних этих EXE для запуска мало — им нужны остальные файлы готового комплекта.

## Размер персонажа

В свежую сборку встроено изменение размера: `/scale 0.5` — уменьшить себя, `/scale 2` — увеличить, `/scale reset` — вернуть как было. Для другого игрока: `/scale "Ник" 2`. Нужны права админа. Размер от `0.25` до `4`, сохраняется после выхода.

Меняются тело, хитбоксы, высота камеры и скорость движения. Видно от первого лица и другим игрокам. Анимации учитывают размер: гигант делает обычные шаги, просто длиннее. В транспорте менять размер нельзя, под низким потолком сервер не даст вырасти.

Чтобы заработало у всех, обновите и сервер, и клиент через свежий установщик. Карта и персонажи сохранятся. В `mods` ничего добавлять не нужно. [Подробности и сборка](docs/character-scale.md).

## Кейсы и подсказки команд

Кейсы открываются из обычного инвентаря. Выпавшие вещи остаются в рюкзаке, ключи списываются вместе с кейсом. Если не хватает места или ключа, ничего не теряется. [Подробности и ограничения](docs/LOOTBOXES.md).

В комплект входит автодополнение: начните писать команду в чате, нажимайте **Tab** для подстановки и **Shift+Tab** для предыдущего варианта. **↑/↓** выбирают подсказку, **Esc** скрывает список. Установщик добавит мод и в уже установленную локалку. [Исходники и сборка](client/command-completion/README.md).

## Как написать свой мод

Проще всего начать с готового примера:

1. Откройте `sdk/example/src/example/HelloMod.java`. Это обычный Java-класс с интерфейсом `ClientMod`.
2. Поменяйте код под себя. Для начала хватит сообщения в `onLoad` через `context.log(...)`.
3. В `sdk/example/stalcraft-mod.properties` задайте свой `id`, название и версию. Если переименовали класс — поправьте `main`, например `example.MyMod`.
4. Соберите:

   ```sh
   python scripts/build.py sdk
   ```

5. Возьмите `build/hello-mod.jar` и положите в папку `mods` совместимого клиента. Перезапустите клиент, сообщение из `onLoad` ищите в его логе.

Имя выходного JAR в этом скрипте пока остаётся `hello-mod.jar`, даже если внутри вы уже поменяли название мода. Имя файла `stalcraft-mod.properties` тоже не меняйте: его ищет загрузчик.

Основные методы мода:

- `onLoad` — загрузка и подготовка.
- `onInput` — клавиатура, мышь и геймпад.
- `onTick` — логика по тикам.
- `onFrame` — вызов каждый кадр, в том числе в меню.
- `registerSettings` — настройки во вкладке мода.
- `registerKeybinds` — регистрация кнопок.
- `registerHud` — элементы HUD.
- `onUnload` — убрать за собой при выгрузке.

Например, кнопку можно объявить так:

```java
public void registerKeybinds(KeybindRegistry keys) {
    keys.register("toggle", "Включить мой мод", 75); // K, код GLFW
}
```

Само действие пишется отдельно в `onInput`: состояние K можно проверить через `input.keyDown(75)`. Метод сообщает, что кнопка удерживается, поэтому для одного переключения на нажатие запоминайте её предыдущее состояние. Одна регистрация кнопки действие за вас не выполнит.

API лежит в [`sdk/api/szmods/api`](sdk/api/szmods/api), пример — в [`sdk/example`](sdk/example). К внутренним классам игры сразу лучше не лезть: там всё привязано к версии клиента.

Подробности запуска — [здесь](docs/QUICKSTART.md), текущие ограничения — [здесь](docs/STATUS.md). Баги и предложения кидайте в Issues: что делали, что ожидали и что получилось.

### Аномалии

Настройки каждой аномалии открываются на F в режиме разработчика и сохраняются в самом объекте карты. У батута также доступны сила, перезарядка и режим импульса. [Как настраивать](docs/ANOMALIES.md).
